# TrajCompare — программа сравнения траекторий скважин

## Как получить TrajCompare.exe

### Способ 1. Собрать на своём компьютере с Windows (около 5 минут)
1. Установите Python 3.10–3.12 с https://www.python.org/downloads/. При установке отметьте **Add python.exe to PATH**.
2. Распакуйте архив в любую папку и дважды щёлкните **build_exe.bat**.
3. Скрипт сам скачает библиотеки и соберёт программу. Готовый файл появится в `dist\TrajCompare.exe`, папка откроется автоматически.

Python нужен только на компьютере, где идёт сборка. Готовый `TrajCompare.exe` (~60–80 МБ) копируется на любые машины с Windows 10/11 и работает без установки.

### Способ 2. Сборка на серверах GitHub (Python не нужен вообще)
1. Загрузите содержимое архива в репозиторий GitHub (можно приватный).
2. Откройте вкладку **Actions** → **Build TrajCompare.exe** → **Run workflow**.
3. Через 3–5 минут скачайте `TrajCompare-windows` в разделе **Artifacts**.

## Работа с программой
Запустите `TrajCompare.exe`. Первый запуск занимает 5–10 секунд: программа распаковывается.

### Основной режим: вкладка «Книга РН-ПД + CSV»
**Исходные данные**
- **Траектории РН-ПД** — один Excel-файл, каждая скважина на своём листе. Имя листа — номер скважины (например, `377Г`). Формат листа — как в выгрузке «Профиль скважины»: заголовки ищутся автоматически.
- **Траектории РНТ** — CSV с разделителем-запятая (десятичная точка). Два варианта:
  - папка с файлом на каждую скважину; номер скважины в имени файла (`377Г.csv`, `РНТ_377Г.csv`, `377Г_alt.csv`);
  - один CSV на все скважины с колонкой `Скважина` (или `Well`).

  Колонки: `MD`, `INCL`, `AZIM`, `TVDSS`, `X north`, `Y east` (русские названия тоже понимаются). Кодировка UTF-8 или Windows-1251.

Номера скважин сопоставляются без учёта регистра, пробелов, дефисов и путаницы кириллицы с латиницей (`377Г-А` = `377г-a`).

**Результат — один Excel-файл**
1. **«Сводная»** — счётчики вердиктов и таблица по всем скважинам. Номер скважины — ссылка на её лист, вердикт подсвечен цветом, есть фильтры.
2. **Лист на каждую скважину** — вердикт, итоговые показатели, параметры обеих траекторий, графики (план, разрез, проекции, 3D, расхождение по стволу, зенит), цели и реперы, таблица расхождения с шагом 25 м. Сверху ссылка «← к сводной».
3. **«Ошибки»** — листы без CSV, CSV без листа, нечитаемые файлы.

Размер итоговой книги — около 90 КБ на скважину, то есть ~90 МБ на 1000 скважин. Без графиков (вкладка «Настройки») — ~20 МБ. Расчёт 1000 скважин на 8 ядрах занимает примерно 2–3 минуты.

### Другие режимы
- **Одна пара.** Выберите файл РН-ПД и РНТ, нажмите «Сравнить». На экране появятся вердикт и ключевые цифры, а также кнопки «Открыть отчёт Excel», «Открыть графики» и «Открыть папку».
- **Пакетная обработка.** Выберите один из способов задать пары:
  - папка, где в каждой подпапке лежит пара файлов;
  - две папки (РН-ПД и РНТ);
  - CSV-список пар.

  Затем нажмите «Запустить». Видны прогресс, журнал и кнопка «Остановить». По окончании открывается сводная таблица.
- **Настройки.** Допуски (цели, устья, расхождение стволов), шаг расчёта, графики вкл./выкл. Настройки и последние пути запоминаются в `TrajCompare_settings.json` рядом с exe.

РН-ПД и РНТ в пакетном режиме распознаются по имени файла: «РН-ПД…» и «РНТ…» (старые «точн…»/«альтерн…» тоже понимаются). Признаки можно поменять прямо в окне.

### Запуск без окна (для планировщика задач или скриптов)
```
TrajCompare.exe workbook --ref-xlsx D:\РН-ПД.xlsx --alt D:\РНТ_csv -o D:\Результат.xlsx --workers 8
TrajCompare.exe batch --root D:\Скважины -o D:\Результаты --workers 8 --skip-existing
TrajCompare.exe pair РН-ПД.xlsx РНТ.xlsx -o D:\Результаты
```

## Состав
- `trajcompare_gui.py` — окно программы (точка входа exe).
- `trajcompare.py` — расчётное ядро.
- `workbook_mode.py` — режим «книга РН-ПД + CSV → одна итоговая книга».
- `build_exe.bat` — сборка на Windows.
- `.github/workflows/build-exe.yml` — сборка на GitHub.
- `samples/` — примеры: пара 377Г, книга `РН-ПД_книга.xlsx` и папка `РНТ_csv` (используются для автопроверки собранного exe).

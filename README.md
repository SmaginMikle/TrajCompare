# TrajCompare — программа сравнения траекторий скважин

## Как получить TrajCompare.exe

### Способ 1. Собрать на своём компьютере с Windows (около 5 минут)
1. Установите Python 3.10–3.12 с https://www.python.org/downloads/. При установке отметьте **Add python.exe to PATH**.
2. Распакуйте архив в любую папку и дважды щёлкните **build_exe.bat**.
3. Скрипт сам скачает библиотеки и соберёт программу. Готовый файл появится в `dist\TrajCompare.exe`, папка откроется автоматически.

Python нужен только на компьютере, где идёт сборка. Готовый `TrajCompare.exe` (~60–80 МБ) копируется на любые машины с Windows 10/11 и работает без установки.

### Способ 2. Сборка на серверах GitHub (Python не нужен вообще)
1. Загрузите содержимое архива в репозиторий GitHub (можно приватный).
2. Откройте вкладку **Actions** → **Build TrajCompare.exe** → **Run workflow**.
3. Через 3–5 минут скачайте `TrajCompare-windows` в разделе **Artifacts**.

## Работа с программой
Запустите `TrajCompare.exe`. Первый запуск занимает 5–10 секунд: программа распаковывается.

### Форматы входных файлов
Формат определяется автоматически, по содержимому файла, — расширение не важно. Программа сама узнаёт:
- тип файла: Excel или текст;
- кодировку: UTF-8 или Windows-1251;
- разделитель CSV: запятая, точка с запятой, табуляция или пробелы;
- десятичный разделитель: точка или запятая;
- формат таблицы.

| Формат | Что это | Пример в программе |
|---|---|---|
| **Структура файла траекторий** | CSV: `MD (m), INCL (grad), AZIM (grad), TVDSS (m), X north (m), Y east (m), TVD (m), dX (m), dY (m)`. Обязательны MD, INCL, AZIM | `Структура_файла_траекторий_пример.csv` |
| **Профиль скважины (выгрузка РН-ПД)** | Excel с шапкой скважины и таблицей «Глубина по стволу / Зенитный угол / Азимут …» | `Профиль_скважины_РН-ПД_пример.xlsx` |
| **Книга Excel: лист = скважина** | Каждый лист — траектория одной скважины в любом из форматов | `Книга_РН-ПД_пример.xlsx` |
| **Один CSV на все скважины** | Столбцы «Структуры файла траекторий» + столбец `Скважина` | `РНТ_все_скважины_пример.csv` |
| Произвольная таблица | Столбцы ищутся по названиям (русским и английским) | — |

Особенности «Структуры файла траекторий»:
- **TVD и TVDSS** различаются точно: `TVD (m)` — глубина по вертикали от устья, `TVDSS (m)` — абсолютная отметка. TVD нужна для DDI по методике 2.
- **Смещения dX/dY** сверяются с координатами X/Y. Расхождение показано в параметрах траектории («QC: расхождение dX/dY…»).
- **Нет X/Y, есть только dX/dY.** Траектории сравниваются от общего устья, в сводной появляется столбец «Примечание».

**Справка в программе** — меню «Справка» или клавиша F1, а также кнопка «? Форматы и примеры» на вкладках:
- описание каждого формата и его столбцов;
- **«Показать пример здесь»** — таблица примера прямо в программе, распознанные столбцы отмечены ✔;
- **«Открыть пример в Excel»**, **«Сохранить пример как…»**, **«Открыть папку с примерами»**;
- **«Проверить формат файла…»** — выбираете свой файл, программа показывает, как она его поняла: тип, кодировку, разделитель, формат, найденные столбцы, число точек.

В Excel с русскими настройками CSV с запятой может открыться в один столбец. Тогда используйте «Показать пример здесь» или в Excel «Данные → Из текста/CSV».

### Основной режим: вкладка «Сравнение по скважинам»
**Исходные данные.** И для РН-ПД, и для РНТ можно указать файл или папку в любом из форматов выше:
- **папка** — все файлы CSV/TXT/XLSX внутри, включая подпапки. Номер скважины берётся из имени файла (`377Г.csv`, `РНТ_377Г.csv`, `377Г_alt.csv`) или из имени листа;
- **книга Excel с несколькими листами** — лист = скважина. Листы, не похожие на траекторию, пропускаются;
- **файл со столбцом `Скважина`** (или `Well`) — делится по скважинам.

Номера скважин сопоставляются без учёта регистра, пробелов, дефисов и путаницы кириллицы с латиницей (`377Г-А` = `377г-a`). На листе каждой скважины подписан распознанный формат обоих файлов, в шапке сводной — сколько файлов какого формата было.

**Результат — один Excel-файл**
1. **«Сводная»** — счётчики вердиктов и таблица по всем скважинам. Номер скважины — ссылка на её лист, вердикт подсвечен цветом, есть фильтры.
2. **Лист на каждую скважину** — сверху ссылки «← к сводной», «→ траектория РН-ПД», «→ траектория РНТ». Далее блок «Расчёт DDI» на формулах, итоговые показатели, параметры обеих траекторий, графики (план, разрез, проекции, 3D, расхождение по стволу, зенит), цели и реперы, таблица расхождения с шагом 25 м.
3. **«Траектории РН-ПД» и «Траектории РНТ»** — исходные точки всех скважин подряд (колонка «Скважина»; её название в первой строке блока — ссылка обратно на лист скважины) и колонки с формулами: ΔMD, угол искривления β, ΔAHD, AHD и Tortuosity нарастающим итогом, DDI нарастающим итогом. Если строк больше миллиона, создаётся продолжение «Траектории РН-ПД (2)».
4. **«Ошибки»** — скважины без пары, нечитаемые файлы (с причиной).

Ячейки с формулами выделены голубой заливкой. Значения сохранены в файле, поэтому видны сразу, даже без пересчёта. Если поправить точку траектории, Excel пересчитает DDI скважины, сводную и итог сравнения.

### Индекс сложности DDI
Методика выбирается во вкладке «Настройки» («Методика расчёта DDI») или ключом `--ddi-method`. Шкала сложности для обеих методик одна: < 6,0 низкая; 6,0–6,4 средняя; 6,4–6,8 высокая; ≥ 6,8 экстремальная.

**Методика 1 — Oag & Williams** (по умолчанию, `--ddi-method oag`), SPE/IADC 59196:

DDI = log₁₀( AHD × MD × Tortuosity / TVD )

- **AHD** — горизонтальный путь вдоль ствола (сумма длин проекций интервалов на план), м;
- **MD** — длина ствола, м;
- **Tortuosity** — сумма пространственных углов искривления по всем интервалам, град;
- **TVD** — вертикальная глубина забоя от устья, м.

**Методика 2 — по смещению от устья** (`--ddi-method closure`):

- D(i) = √(ΔX(i)² + ΔY(i)²) — суммарное смещение от устья (ΔX — на Север, ΔY — на Восток), м;
- T(i) = T(i−1) + α(i)/10 × (M(i) − M(i−1)), T = 0 в первой строке — извилистость, град. Здесь α — пространственная интенсивность на интервале, град/10 м (метод минимальной кривизны);
- DDI = log₁₀( M × D × T / V ) — M и V: глубина по стволу и по вертикали на забое, D и T — на забое.

При методике 2 листы траекторий содержат столбцы из задания: глубина по стволу, глубина по вертикали, пространственная интенсивность, смещения на Север и Восток, формулы «Смещение от устья», «Извилистость» и DDI нарастающим итогом. Справа — исходные зенит, азимут, TVDSS, координаты.

Для 377Г: методика 1 даёт DDI 5,977 (РН-ПД) / 5,908 (РНТ), методика 2 — 5,773 / 5,724. Методика 2 ниже, потому что смещение на забое (2089 м) меньше пути в плане (3338 м).

Цепочка формул:
- **лист траекторий:** по методике 1 — β и ΔAHD по каждому интервалу → AHD и Tortuosity нарастающим итогом → DDI нарастающим итогом; по методике 2 — D и T по формулам задания → DDI нарастающим итогом. Последняя строка скважины — итоговый DDI;
- **лист скважины, блок «Расчёт DDI»:** составляющие (AHD/D, MD/M, Tortuosity/T, TVD/V) берутся ссылками с листов траекторий, далее DDI, разница, категория сложности и итог сравнения. Применённая методика подписана над блоком и в шапке сводной;
- **сводная:** колонки «Сравнение по DDI», «DDI РН-ПД», «DDI РНТ», «ΔDDI» ссылаются на листы скважин; вверху — средние DDI и число скважин в каждой группе (тоже формулами).

Итог сравнения: «РНТ проще», «РНТ сложнее» или «сопоставимы». Порог «сопоставимы» (|ΔDDI| < 0,1) хранится в ячейке на листе «Сводная» и меняется прямо в Excel. Значение по умолчанию задаётся во вкладке «Настройки».

Размер итоговой книги — около 270 КБ на скважину, то есть ~270 МБ на 1000 скважин. Без листов траекторий («Настройки» или ключ `--no-traj`) — ~90 КБ на скважину, без графиков — ещё меньше. На 1000 скважин расчёт на 8 ядрах занимает 2–3 минуты, запись листов траекторий — ещё 5–7 минут.

### Другие режимы
- **Одна пара.** Выберите файл РН-ПД и РНТ, нажмите «Сравнить». На экране появятся вердикт и ключевые цифры, а также кнопки «Открыть отчёт Excel», «Открыть графики» и «Открыть папку».
- **Пакетная обработка.** Выберите один из способов задать пары:
  - папка, где в каждой подпапке лежит пара файлов;
  - две папки (РН-ПД и РНТ);
  - CSV-список пар.

  Затем нажмите «Запустить». Видны прогресс, журнал и кнопка «Остановить». По окончании открывается сводная таблица.
- **Настройки.** Допуски (цели, устья, расхождение стволов), шаг расчёта, графики вкл./выкл. Настройки и последние пути запоминаются в `TrajCompare_settings.json` рядом с exe.

РН-ПД и РНТ в пакетном режиме распознаются по имени файла: «РН-ПД…» и «РНТ…» (старые «точн…»/«альтерн…» тоже понимаются). Признаки можно поменять прямо в окне.

### Запуск без окна (для планировщика задач или скриптов)
```
TrajCompare.exe workbook --ref-xlsx D:\РН-ПД.xlsx --alt D:\РНТ_csv -o D:\Результат.xlsx --workers 8
TrajCompare.exe batch --root D:\Скважины -o D:\Результаты --workers 8 --skip-existing
TrajCompare.exe pair РН-ПД.xlsx РНТ.csv -o D:\Результаты
TrajCompare.exe formats                       # список форматов и их столбцов
TrajCompare.exe example traj_struct -o D:\   # сохранить пример «Структуры файла траекторий»
TrajCompare.exe detect D:\мой_файл.csv        # как программа распознала файл
```
Exe собран без консоли, поэтому вывод команд `formats` и `detect` виден только при запуске из `python trajcompare.py …`. Для проверки формата в exe используйте меню «Справка → Проверить формат файла…».

## Состав
- `trajcompare_gui.py` — окно программы (точка входа exe).
- `trajcompare.py` — расчётное ядро.
- `workbook_mode.py` — режим «Сравнение по скважинам → одна итоговая книга».
- `examples/` — примеры форматов для справки; упаковываются внутрь exe.
- `build_exe.bat` — сборка на Windows.
- `.github/workflows/build-exe.yml` — сборка на GitHub.
- `samples/` — примеры: пара 377Г, книга `РН-ПД_книга.xlsx` и папка `РНТ_csv` (используются для автопроверки собранного exe).
